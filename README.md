# Dalio Uncorrelated Returns – Portfolio Management

A research and implementation repository for building **uncorrelated-return portfolios** inspired by Ray Dalio’s principle of combining multiple independent return streams. The project provides notebooks, a full portfolio recommender pipeline, and supporting research notes on asset selection, risk parity, and weighting.

---

## What This Repo Does

1. **Introduces the concept** of uncorrelated returns and diversification across asset classes (equities, fixed income, commodities, crypto, etc.) in a small, hands-on notebook.
2. **Builds a portfolio recommender** that:
   - Defines a liquid, multi-asset universe (by region, factor, maturity/credit, commodities, inflation hedges, volatility, crypto).
   - Loads and preprocesses historical prices (with optional caching).
   - Converts to returns and analyzes **correlations** and **hierarchical clusters**.
   - Selects a diversified subset via clustering (e.g., optimal \(k\) with gap statistic).
   - Weights **within each cluster** (e.g., inverse-vol or risk-based rules) and **across clusters** via **risk parity**.
   - Evaluates the recommended portfolio (out-of-sample returns, drawdowns, volatility, risk contributions) and optionally extends to a recent period (e.g., January 2026).

The goal is to produce a **single set of asset weights** that balance diversification (uncorrelated streams) and risk (each cluster contributing similarly to total portfolio risk).

## PortfolioCreator Pipeline (High-Level)

The main notebook `portfolio_creator.ipynb` is organized in numbered sections:

| Section | What it does |
|--------|----------------|
| **0** | Setup and imports (pandas, numpy, yfinance, riskfolio, scipy, plotting). |
| **1** | Define the liquid asset universe (see `research/asset_categories.md`). |
| **2** | Load and preprocess historical data (train/test split); cache to CSV if desired. |
| **3** | Prices → returns; correlation matrix; hierarchical clustering; optimal \(k\); save clustering artifacts to `data/portfolio_creator_data/training/`. |
| **4** | Intra-cluster weights (e.g., inverse-vol or cluster-specific rules from `research/how_to_weight_assets.md`). |
| **5** | Build cluster-level return series; allocate across clusters with **risk parity**; combine to final asset weights. |
| **6** | Testing and visualization: benchmark, out-of-sample returns, drawdowns, rolling volatility, cluster contributions, worst days, performance summary. |
| **7** | Extension (e.g., January 2026): load cached recent prices, compute returns, apply portfolio, compare performance. |

## Getting Started

1. **Clone the repo** (no `data/` included; it will be created when you run the notebooks).

2. **Create and activate a virtual environment** (recommended):
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the notebooks in order:**
   - Open **`introduction.ipynb`** in Jupyter and run all cells to get context and a small correlation example.
   - Open **`portfolio_creator.ipynb`** and run from top to bottom. The first run will fetch price data (e.g., via yfinance) and can save it under `data/` for faster reruns.

5. **Optional:** Read the **`research/`** markdown files to understand asset choice (e.g., `asset_categories.md`, `factors.md`, `fixed_income.md`) and weighting (e.g., `risk_parity.md`, `inverse_volatility.md`, `how_to_weight_assets.md`).

## Key Concepts (and Where They’re Documented)

- **Uncorrelated returns** – Combining assets/clusters that don’t move in lockstep to improve risk-adjusted outcomes. Introduced in `introduction.ipynb`.
- **Risk parity** – Allocating so each cluster (or asset) contributes equally to portfolio risk. See **`research/risk_parity.md`** and Section 5 of `portfolio_creator.ipynb`.
- **Inverse-volatility weighting** – Weights proportional to \(1/\sigma\) within a cluster. See **`research/inverse_volatility.md`** and **`research/how_to_weight_assets.md`**.
- **Universe design** – Regions (GDP), factors, fixed income (maturity/credit), commodities, inflation hedges, volatility, crypto. See **`research/asset_categories.md`**, **`research/factors.md`**, **`research/fixed_income.md`**, **`research/inflation_and_volatility.md`**.
